## What changed

**The GWAS annotations were reconciled with the frozen species set.** The GWAS ran
in March; the species set was curated on 2026-09-16 and the annotation tables never
saw that curation. `71_filter_annotations_to_frozen_set.R` now keeps a candidate
gene only where its species is in that trial's frozen set, and archives the
unfiltered files to `data/gene_annotation_final/raw/` so the step is idempotent.
Five trait names go, listed in `data/gene_annotation_final/traits_removed_vs_frozen_set.tsv`.

The consequential one is `13-Keto-9Z,11E-octadecadienoic acid`, which is the same
MS feature as `13S-HOTrE`. Both names carried hits over an identical 420-gene set,
so every one of those LIN genes was credited with two phenotypes for one lipid.
13S-HOTrE itself is untouched: 420 genes before, 420 after, same set.

Two lyso species are also written as the curated set writes them,
`PC(18:2/0:0)` as `LPC(18:2)` and `DG(18:0/18:2/0:0)` as `DG(18:0/18:2)`.

**The supplement went from 31 tables to 29.** The four GWAS candidate tables became
two, one per trial, with a leading `Layer` column reading `individual` or
`sum_ratio`. Everything from the old S23 onward moves down by two.

**S9 was the wrong table.** It carried `final_lipid_classes.csv`, the class lookup,
which has 316 rows because it still lists every annotation the curation merged away,
`13-Keto` among them, while `main.tex` cites it twice as the frozen species set.
S9 is now the curated 266 with the lookup's category and subclass tiers joined on
(`79_build_frozen_species_table.R`), giving the 214 / 216 / 164 split the text quotes.
